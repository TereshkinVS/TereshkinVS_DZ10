## Описание уязвимости

CVE-2022-50890 — уязвимость обхода пути (Path Traversal) в Owlfiles File Manager 12.0.1.  
Удалённый атакующий может сформировать специальный HTTP-запрос с последовательностями `../` в параметре пути и получить доступ к произвольным файлам в пределах прав веб-сервера.

## PoC-скрипт

Файл `poc_cve_2022_50890.py` имитирует запрос к условной уязвимой конечной точке веб-приложения и выводит:
- сообщение о потенциальной атаке,
- фрагмент ответа сервера при подозрении на эксплуатацию,
- либо сообщение об отсутствии признаков уязвимости.
